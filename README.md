# Piedmont Community Pool — Summer Guide

A mobile-friendly, single-page web guide for the **Piedmont Community Pool** summer schedule (June 8 – July 19, 2026).

**Live site:** https://berzerker162.github.io/piedmont-pool-guide

## What's included

- Full weekly schedule for both pools — **Settlemier Competition Pool** and **Activity Pool**
- Color-coded activity blocks: lap swim, open swim, rec swim, lessons, and camps
- "Today" highlight so you can instantly see what's available right now
- Pool hours, swim tips, and registration info

## Pools

| Pool | Notes |
|---|---|
| Settlemier Competition Pool | 777 Magnolia Ave · 8 lap lanes mornings, open/rec swim afternoons |
| Activity Pool | Warm water · lessons Mon–Thu + Sat/Sun · Happy Splashers Fridays |

## Tech

Single self-contained HTML file — no build step, no dependencies beyond Google Fonts.

## Updating

Replace `index.html` with a new version and push to `main`. GitHub Pages serves the update within ~1 minute.
